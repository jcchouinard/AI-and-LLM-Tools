# Learnings

- Chrome `--print-to-pdf` gave wrong page sizes and black space in LinkedIn's preview. JPEG-per-page PDF fixed it.
- A single wide strip with per-page `translateX` makes seam-crossing visuals easy.
- Padding the card edge (empty 180 px, 120 px peeking into the prior slide) prevents clipped annotations.
- Headlines over about 28 chars wrap into the subtitle at 66px. Shorten them.
- Newsletter feed crop removes about 125 px per side, so keep content in x 150-1050.
- X crops the 4-image grid. Keep content inside x 160-1440, y 90-810 and check a real preview if text looks tight.
- The 4 tweet images should read as a mini-story: cover, key steps, payoff or CTA.
- Verify claims against screenshots (for example which bar is tallest) before writing copy.
- The last-slide button must not touch the arrow.
- Iterating by version (v2, v3, v4) worked well: tweak spacing, card sizes, and copy, then rebuild.
